# Image Analysis

`ImageAnalyzer` reports width, height, channel count, format, bit depth, luminance statistics, histogram, dark/highlight/overexposed ratios, RGB means, color-cast estimate, RMS contrast, dynamic range, sharpness estimate, noise estimate, image entropy, local luminance non-uniformity, total pixels, tile recommendation, and estimated memory.

These are statistical estimates and reference indicators. They are not absolute professional diagnoses and are not used to invent indoor/outdoor scene labels.
